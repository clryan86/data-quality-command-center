# Recruiter Overview

**Data Quality Command Center** demonstrates practical data-engineering work beyond dashboards: incoming data is profiled, checked against reusable contracts, scored, and tracked over time.

Skills demonstrated include Python, Pandas, FastAPI, data profiling, validation engineering, statistical anomaly detection, SQLite, REST APIs, CLI tooling, automated testing, Docker, and CI/CD.

The included dirty customer dataset makes the demo immediately reproducible and shows how the system surfaces realistic defects instead of relying on a perfect toy dataset.
